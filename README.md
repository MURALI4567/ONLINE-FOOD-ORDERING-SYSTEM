## 📌 Project Overview

The **AI Online Food Ordering System** is an intelligent food ordering platform developed using **Python**. The system allows users to browse menus, place food orders, manage customer information, and receive AI-based recommendations based on their preferences and ordering history.

The project aims to improve the food ordering experience through automation, personalization, and efficient order management.

---

## 🎯 Features

✅ User Registration and Login

✅ Restaurant Menu Management

✅ Food Search and Filtering

✅ Add to Cart Functionality

✅ Order Placement and Tracking

✅ Bill Generation

✅ AI-Based Food Recommendations

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/narendhra-vs-06/AI-Online-Food-Ordering-System.git
```

### Navigate to Project Folder

```bash
cd AI-Online-Food-Ordering-System
```

### Install Required Packages

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```

## 🧠 AI Module

The AI recommendation system analyzes:

* Previous Orders
* User Preferences
* Popular Food Items
* Frequently Ordered Combinations

Based on these factors, the system suggests personalized food choices to users.
